ESP32: ootan ühendust…

ESP32 pole võrgus (pole viimase 3 s jooksul serveriga ühendust võtnud).

• Kas ESP32-l on COLLECTOR_MODE 1 firmware? Tuvastusrežiimis see serveriga ei suhtle.

• LED vilgub siniselt → ei saa WiFi-ga ühendust: kontrolli WIFI_SSID / WIFI_PASSWORD (ainult 2.4 GHz).

• LED vilgub kollaselt → WiFi on, aga server ei vasta: SERVER_HOST peab olema selle masina IP, rakendus käivitatud python app.py --host 0.0.0.0 ja tulemüür peab Pythonit lubama.

• Detailid: Arduino IDE → Serial Monitor (115200 baud).

Praegune tase (peak) 0.000 · -∞ dBFS

Räägi mikrofoni, tase uueneb iga 100 ms järel.

võrgu ringaeg: – ms · heli puhvri viivitus: – ms

Kuidas tulemust lugeda

Kui peak < 0.01 rääkides, on mikrofon liiga vaikne — tule lähemale või kontrolli juhtmeid.

Kui peak > 0.9 pidevalt, mikrofon lõikab (clipping) või on juhtmestikuga probleem.

Vaikuses peaks tase olema väike, aga mitte täpselt 0 — täielik 0 viitab puuduvale andmesignaalile (SD/WS/SCK juhtmed). Kui tase on alati 0, kontrolli et INMP441 L/R on GND-s; proovi ka config.h-s #define I2S_MIC_SLOT I2S_STD_SLOT_RIGHT.

"Heli puhvri viivitus" üle ~1000 ms tähendab aeglast WiFi-t.
